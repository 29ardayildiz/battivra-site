# battivra-site

Public pages for the Battivra app, served with GitHub Pages at
https://29ardayildiz.github.io/battivra-site/

- `/` — short app page
- `/privacy/` — Privacy Policy (App Store privacy policy URL)
- `/support/` — Support and contact (App Store support URL)

Plain HTML and CSS, no build step. `.nojekyll` turns off Jekyll processing.
